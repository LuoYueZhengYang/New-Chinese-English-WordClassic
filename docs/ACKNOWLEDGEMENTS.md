# 思想启发与作品致谢

## 白话文运动的启发

发起人王正阳（笔名）将白话文运动视为本项目的思想启发，向胡适、陈独秀、钱玄同、鲁迅等相关历史人物致意。项目借鉴的是让表达接近普通生活、让更多人参与知识交流的方向，不宣称两种语言变革具有相同机制或结果。

历史人物的思想立场并不相同，也不是本项目的实际参与者。有关《新青年》与白话文运动，可参阅北京大学新闻网所载的[胡适回忆《新青年》和白话文运动](https://news.pku.edu.cn/info/2831/51781.htm)。

## 感谢二目与放开那个女巫

感谢二目创作《放开那个女巫》。作品只作为不公开的本地语言测试材料；公开仓库仅保留致谢和个人阅读感受，不发布小说原文、试译及逐段对照。

王正阳的个人阅读感受是：“我在作品中读到了与我所理解的新中国共产主义相呼应的解放、教育与共同建设的思想。”

上述思想解读由发起人提出，不代表二目的自述，也不表示作者参与、认可或背书本项目。小说及相关权利属于相应权利人，第三方作品不在本项目许可范围内。旧小说样本已从公开内容撤下，原文件、试验副本及本地来源记录继续留在本地，见[素材范围](../samples/README.md)。

## 实际贡献

发起人、词条贡献者、规则讨论者、测试学习者和工具维护者按真实贡献记录署名。历史启发人物、原作作者与项目贡献者分别列示，避免混淆。
