# 王正阳的 WordClassic 发起宣言

知识的进步，不单单依靠一个人的力量，而依靠人类共同的智慧。

我叫王正阳，这是我的笔名。我自然希望在历史中留下名字，但更希望留下一个人人能够质疑、修订、使用和继续建设的项目。

我相信：“神不是凌驾于人之上的，而是服务于人的。”对我而言，知识、技术与语言规则也应服务于人，让更多人获得学习、表达和创造的机会。

白话文运动给予我的启发，是让表达更加接近普通人的生活。我向胡适、陈独秀、钱玄同、鲁迅等相关历史人物致意。我的项目并非他们的续作或共同作品，而是一个从这种表达革新精神获得启发的当代实验。

我希望以关注新中国共产主义、人的解放、教育普及与共同建设的各界人士为协作核心，共同创造 New Chinese English WordClassic。作为承接中国五千年文化传统的一名学习者，我希望把自己理解的“解放、教育、指导”落实为具体的知识劳动：整理词义，解释规则，倾听学习者，再修正表达。

感谢二目的《放开那个女巫》。我在这部作品中读到了与我所理解的新中国共产主义相呼应的思想。这是我的个人阅读感受，不是替作者声明立场；我把它选作最初的本地试译样品，也希望尊重作品和作者。

我们从一个词、一条规则、一句读得懂的话开始。基础词保留熟悉的读音，组合尽量清楚，规则接受检验，贡献得到记录。愿这个项目依靠共同的智慧成长，而不是依靠某个人的权威成立。

——王正阳（笔名）
