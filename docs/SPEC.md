# WordClassic 初始试行规则（0.1.0）

本规范记录当前讨论方向与公开试行数据，版本为 0.1.0。WordClassic 是一种新表达体系的实验，不把试行表达标成现行标准英语。

此文件保留初始词库和 60 句的版本背景。后续组合优先方向、308 单位词库及 milk 义项迁移见 [0.2 简单表达思路](SPEC-v02.md)。旧 60 句保留原样，第三方小说原文和试译不在公开范围。

## 已明确的设计方向

1. 基础词使用既有英语词形及原有读音，不从零制造音系。
2. 已选基础义使用固定表达；构词以清楚的词义关系为依据。
3. 一个基础词已完整表达意思时直接使用；需要增加信息时再组合。
4. 中文组合结构是设计参考，不是对每一个汉字进行脱离语境的替换。
5. 约 5000 个基础单位是长期建设目标。现阶段先检验小词表与真实阅读。

## 基础词与组合词

基础词是词库中单独登记的单位；组合词由已登记单位按顺序连接。

| 中文意思 | 表达 | 说明 |
| --- | --- | --- |
| 师、老师 | teacher | “老师”中的“老”在这里不表达年龄 |
| 年老 | old | 年龄信息的基础义 |
| 人 | person | 人的基础义 |
| 老人 | oldperson | old + person |
| 类别 | class | 当前义项；其他义项另行讨论 |
| 人类 | personclass | person + class |

正式样例采用连写；教学中可用 `person-class` 标明边界。基础词本身保留原读音，组合时按词根顺序读；口音、重音、连读细节和音标方案仍待统一。

## 数字规则

- 0—9：zero、one、two、three、four、five、six、seven、eight、nine。
- 10：ten。
- 11—19：ten + 个位基础词，例如 tenone、tentwo。
- 20—99：十位基础词 + ten + 非零个位基础词；整十省略个位。

例如 20 = twoten，21 = twotenone，32 = threetentwo，99 = ninetennine。此版本的生成器范围为整数 0—99；百位、小数、负数及序数另行设计。

## 60句中的试行句式

以下是当前语料使用的提案，并非已经完成全语言验证的定稿规则。

- 动作使用基本词形；数量后名词暂不增加复数词尾：`I have two book.`
- 时间位于主语之后、动作之前：`I tomorrow see you.`
- no 放在被否定的部分前：`I no want drink tea.`
- 身份句暂省略系词：`I teacher.`
- 位置用 at：`Teacher at school.`
- 是非问句暂借助疑问语调和问号：`You want drink tea?`

关于宾格、领属、比较、复杂从句、完成状态等问题，应通过新提案分别设计。早期本地小说试译中探索过的处理方式，不自动升级为公开核心规范。

## 词义区分

- 想要：want；思考：think。
- 阅读：read；看见：see。
- 字、字符：character；词、词语：word。

同一汉字在不同词中可能承担不同意义。多义字的义项编号、一个英语基础词的多义边界，以及同义词的取舍，是后续词库建设的重要议题。

## 检验方法

请学习者只学习基础词，再阅读未背过的组合词和句子，分别记录：

1. 理解的意思是否与原意相符。
2. 朗读是否顺畅，哪些组合难以辨认或发音。
3. 是否出现否定、时间、数量或关系的歧义。
4. 面对不同母语的学习者，困难是否发生变化。

规则变化时同步修改数据、示例和测试，并记录版本差异。
