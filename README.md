# New Chinese English WordClassic

**发起人：王正阳（笔名）**

一个以中文词义结构为参考、保留英语基础词原有读音的语言简化实验。我们希望用有限的基础单位和可推导的组合规则，降低学习、表达与知识传播的门槛。长期词库目标约为 **5000 个基础单位**；当前版本是起步草案，并非现行标准英语教材。

知识的进步不单单靠一个人的力量，而靠人类共同的智慧。项目从白话文运动获得启发，希望以关注新中国共产主义、人的解放、教育普及和共同建设的各界人士为协作核心，把语言实验变成可讨论、可检验、可继续建设的共同工作。完整理念见[发起人宣言](docs/MANIFESTO.zh-CN.md)。

## 从几个例子开始

| 中文意思 | WordClassic | 构词思路 |
| --- | --- | --- |
| 人 | person | 固定基础义 |
| 类 | class | 本项目当前取“类别”这一义项 |
| 人类 | personclass | person + class |
| 师、老师 | teacher | 单个基础词已表达完整词义 |
| 老人 | oldperson | old + person；年龄信息需要保留 |
| 十一 | tenone | ten + one |
| 十二 | tentwo | ten + two |
| 二十 | twoten | two + ten |
| 我想喝茶。 | I want drink tea. | 试行简短句式 |
| 你明天来学校吗？ | Tomorrow, you come school? | 先说时间，问句用问号和语调 |

基础词的发音沿用原英语；新组合按所列词根顺序读。是否真的更容易学、更顺口，要由学习者的理解、朗读和歧义测试来检验。

## 我们现在采用的简单思路

**单词保持原来的样子，时间用时间词说明，长句拆成短句。**

| 中文 | WordClassic |
| --- | --- |
| 很久以前，我生活在天上。 | A long time ago, I live in sky. |
| 昨天我喝水。 | Yesterday, I drink water. |
| 现在我喝水。 | Now, I drink water. |
| 明天我喝水。 | Tomorrow, I drink water. |
| 我有两本书。 | I have two book. |
| 我不想喝茶。 | I no want drink tea. |

`live` 不因过去变成 `lived`，`drink` 不因时间变成 `drank`，`book` 不因数量变成 `books`。先把什么时候、谁、做什么说清楚，让人从句子直接理解意思。这里展示的是 WordClassic 的表达，不把它当作标准英语纠错题。

新意思尽量由熟悉单位组合：`male + pig → malepig`、`cattle + meat → cattlemeat`、`dried + grape → driedgrape`。组合时每个单位仍保持原样；数字也沿用 `tenone`、`tentwo`、`twoten` 这样的规则。普通读者先看例句和词义，详细数据供协作核对使用。

## 当前公开内容

- **308 个新版试行基础单位、14 个组合**：[0.2 试行词库](data/lexicon-v02.json)、[新版规则与义项迁移](docs/SPEC-v02.md)。其中新增 236 个基础单位与 12 个词族组合；由发起人同意用于试行，不表示学习效果已经验证。
- **72 个初始基础词条、2 个初始组合**：[0.1 基础词表](data/roots.json)、[初始组合表](data/compounds.json)。旧数据与旧句例保留作版本对照。
- **0—99 共 100 个数字条目**：[数字表](data/numbers.json)。
- **60 句原创试行例句**：[句库](data/sentences.json)。
- [样本与素材范围](samples/README.md)：公开部分只保留项目原创例句。第三方小说原文、试译及逐段对照均已撤下，原文件与试验副本只留本地。
- [新版规则](docs/SPEC-v02.md)、[初始规则](docs/SPEC.md)、[参与方式](CONTRIBUTING.md)、[致谢](docs/ACKNOWLEDGEMENTS.md)。
- 数字生成、例句校验、隐私检查和可重复生成的阅读页。

5000 是词库建设目标，不是已完成数量，也不是“认识固定数量的单位就能理解所有文章”的保证。基础义、组合词和完整句子分别记录，避免混计。

## 参与建设

欢迎通过 Issue 提出词条、歧义、发音负担或阅读困难，通过 fork → Pull Request → 维护者审核 → 合并提交改进。外部参与者通过自己的 fork 工作，仓库不开放外部直接写入，也不启用自动合并。请附上中文义项、基础词或构词拆分、例句以及你的检验方法。项目对规则进行讨论，不以对某种自然语言的贬低作为结论。

阅读[贡献指南](CONTRIBUTING.md)与 [DCO](DCO)。贡献 PR 的每个提交需要贡献者本人确认来源及提交资格并签署；签署姓名和邮箱会公开，建议使用本人 GitHub 账号的隐私邮箱。审核与 DCO 都不代替目标文件的许可条件。

## 阅读与验证

需要 Node.js 22 或更新版本，无第三方依赖。

```sh
npm test
npm run check
npm run build
```

构建后打开 `public/index.html`，即可阅读新版基础单位与组合，以及保留的初始词表、数字和原创句子。构建过程不读取本地小说资料。`npm run check` 核对初始数据、新版词库、许可文件及发布排除范围。
